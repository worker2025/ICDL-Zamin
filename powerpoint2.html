ارباب، شاه و کاهن
از یک قماشند

سه ستون قدرت که در ظاهر جدا به نظر می‌رسند، اما در واقع یک پیکر واحد را می‌سازند که بر شانه‌های مردم ایستاده است.

«آدم‌ها مثل آب‌اند؛ راه را که ببندی، راه دیگری پیدا می‌کنند.» — هانی، فصل ۴

🏛️ سه ستون قدرت در رمان

در رمان «زمین خواهد شنید»، ساختار قدرت در سه نهاد تجسم می‌یابد. هر کدام نقشی جدا ایفا می‌کنند، اما همه در یک چیز مشترک‌اند: زندگی بر دوش مردم.

🏠

ارباب

هوټران، مباشر ارباب
  • خراج می‌گیرد
  • نام بدهکاران را روی لوح می‌نویسد
  • می‌گوید: «هر سال تعداد آن‌ها بیشتر می‌شود»
  • وقتی شورا شکل می‌گیرد، می‌گوید: «اعتماد ندارم»
👑

شاه

هانی، پسر تاهی‌هی
  • «کوتور» (نگهبان) است
  • خودش نمی‌داند نگهبان چه چیز است
  • سنگ‌نگاره می‌سازد: «۲۰ تن را اسیر کردم»
  • وقتی مردم شورا می‌سازند، می‌گوید: «فرمان از دستمان بیرون رفته»
🕯️

کاهن

کاهن اعظم معبد نارسینا
  • لوح می‌خواند: «خدایان مرا یاری کردند»
  • می‌گوید: «مردم همیشه رنج کشیده‌اند»
  • وقتی شورا شکل می‌گیرد: «سهم معبد از داوری کمتر می‌شود»
  • خون را به نام خدایان تقدیس می‌کند

⛓️ یک نظام واحد
«هر سه از یک سفره می‌خورند؛ سفره‌ای که دهقان پهن می‌کند.»
— آتا، پیرمرد گلِ شور
💡 نکته‌ی کلیدی: در رمان، هیچ‌کدام از این سه نهاد به تنهایی نمی‌تواند حکومت کند. شاه به کاهن نیاز دارد تا فرمانش رنگ مقدس بگیرد؛ کاهن به شاه نیاز دارد تا معبدش از خراج سیر شود؛ و ارباب به هر دو نیاز دارد تا خراج را از مردم بگیرد و به بالا بفرستد. اما همه‌ی این‌ها بدون مردم هیچ‌اند.

📜 شواهد از متن رمان

این نقل‌قول‌ها از فصل‌های مختلف رمان، هم‌قماش بودن این سه نهاد را نشان می‌دهند:

فصل ۳ — گلِ شور
هر سال سهمش را می‌خورد و باز گرسنه‌تر می‌شود.
هوهین درباره‌ی سهم دهقان می‌گوید. کیسه‌ی پاره‌ای که جو از آن می‌ریزد، نماد سهم مردم است. ارباب، شاه و کاهن هر سه از یک کیسه‌ی دیگر می‌خورند.
فصل ۳ — گلِ شور
خدا را بیشتر در دست‌های مردم دیده‌ام تا در این سنگ‌ها.
هالژ در معبد شوش فریاد می‌زند. این جمله، مرز میان کاهن رسمی و ایمان مردمی را نشان می‌دهد. کاهن به سنگ نیاز دارد، مردم به دست.
فصل ۴ — آیاپیر
بعضی دژها را با نردبان می‌گیرند، بعضی را با قصه.
شوترورو درباره‌ی نقش کاهنان و قصه‌گویان می‌گوید. کاهن با قصه، فرمان شاه را مقدس می‌کند.
فصل ۹ — خاموشی فرمان
اگر چنین باشد، دیگر شاه چه فرقی با یک کدخدا دارد؟
کاهن وقتی می‌بیند هانی از آتش زدن دهکده‌ها منصرف شده، می‌پرسد. او نگران از دست رفتن قدرت شاه است — چون قدرت خودش به شاه وابسته است.
فصل ۱۰ — خونگ‌آژدر
خدایان شکم ندارن که سیر بشن. این شکم شاه بود که سیر نمی‌شد.
مامورو درباره‌ی سنگ‌نگاره‌ها می‌گوید. او مرز میان بهانه‌ی مقدس و منفعت مادی را آشکار می‌کند.
فصل ۱۲ — اشکفت‌سلمان
اگر مردم خودشان داوری کنند، سهمِ معبد از داوری کمتر می‌شود.
دو کاهن وقتی می‌بینند مردم شورا تشکیل داده‌اند، نگران می‌شوند. این جمله پرده از هم‌دستی کاهن و شاه برمی‌دارد.

📊 جدول مقایسه‌ای سه نهاد

این جدول نشان می‌دهد که ارباب، شاه و کاهن در ظاهر متفاوت‌اند، اما در عمل یک کار انجام می‌دهند:

ویژگی 🏠 ارباب 👑 شاه 🕯️ کاهن 🔗 وجه اشتراک
منبع درآمد خراج از دهقان خراج از آبادی‌ها سهم معبد از خراج همه از یک خراج
بهانه نظم و اداره حفاظت از سرزمین خواست خدایان همه بهانه می‌تراشند
رابطه با مردم مباشر و مأمور سپاه و فرمان نیایش و آیین همه از مردم جدا هستند
ترس اصلی کم شدن خراج از دست رفتن فرمان کم شدن سهم معبد ترس از بیداری مردم
واکنش به شورا «اعتماد ندارم» «فرمان از دست رفت» «سهم معبد کم می‌شود» همه مخالف شورا
سرنوشت در رمان هوټران می‌ماند و حساب‌ها را نگاه می‌کند هانی کاخ را ترک می‌کند کاهن به شورا تن می‌دهد همه در برابر مردم تسلیم می‌شوند

  <script>
    const questions = [
      {
        q: 'در رمان، هوټران نماینده‌ی کدام نهاد است؟',
        options: ['کاهن', 'ارباب', 'شاه', 'مردم'],
        answer: 'ارباب'
      },
      {
        q: 'کاهن اعظم وقتی شورا شکل می‌گیرد، نگران چیست؟',
        options: ['کم شدن سهم معبد', 'جنگ', 'قحطی', 'آب'],
        answer: 'کم شدن سهم معبد'
      },
      {
        q: 'هانی خودش را چه می‌نامد؟',
        options: ['شاه', 'کوتور (نگهبان)', 'کاهن', 'ارباب'],
        answer: 'کوتور (نگهبان)'
      },
      {
        q: 'جمله‌ی «خدایان شکم ندارن، این شکم شاه بود که سیر نمی‌شد» از کیست؟',
        options: ['نیکا', 'مامورو', 'هانی', 'آتا'],
        answer: 'مامورو'
      },
      {
        q: 'چه چیزی ارباب، شاه و کاهن را به هم پیوند می‌دهد؟',
        options: ['خون', 'خراج مردم', 'زمین', 'جنگ'],
        answer: 'خراج مردم'
      }
    ];

    let currentQ = 0;
    let score = 0;

    function startQuiz() {
      currentQ = 0;
      score = 0;
      document.getElementById('result').textContent = '';
      showQuestion();
    }

    function showQuestion() {
      if (currentQ >= questions.length) {
        document.getElementById('quiz').innerHTML = '';
        document.getElementById('result').textContent =
          'امتیاز شما: ' + score + ' از ' + questions.length;
        return;
      }

      const q = questions[currentQ];
      let html = '<div class="question">' + (currentQ + 1) + '. '  + q.q + '</div>';

      q.options.forEach(opt => {
        html += '<button class="option" onclick="checkAnswer(this, \'' + opt + '\')">' + opt + '</button>';
      });

      document.getElementById('quiz').innerHTML = html;
    }

    function checkAnswer(btn, opt) {
      const correct = questions[currentQ].answer;
      const buttons = document.querySelectorAll('.option');
      buttons.forEach(b => b.disabled = true);

      if (opt === correct) {
        btn.classList.add('correct');
        score++;
      } else {
        btn.classList.add('wrong');
        buttons.forEach(b => {
          if (b.textContent === correct) b.classList.add('correct');
        });
      }

      currentQ++;
      setTimeout(showQuestion, 1200);
    }

    startQuiz();
  </script>
