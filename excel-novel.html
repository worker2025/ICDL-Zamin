📊 تمرین‌های اکسل — رمان «زمین خواهد شنید»

هفت تمرین اکسل با شخصیت‌های رمان

از ورود داده و قالب‌بندی تا Pivot Table و گزارش نهایی — ویژه‌ی کلاس ICDL

این تمرین‌ها برای کلاس ICDL طراحی شده‌اند و با استفاده از محتوا و شخصیت‌های رمان «زمین خواهد شنید»، مهارت‌های اکسل را تمرین می‌کنید. از ورود داده و قالب‌بندی ساده تا توابع شرطی، نمودارها، Pivot Table و گزارش نهایی.

🧑‍🤝‍🧑 تمرین ۱: جدول شخصیت‌ها ورود داده، قالب‌بندی، مرتب‌سازی و فیلتر

هدف: آشنایی با ورود داده، قالب‌بندی جدول، مرتب‌سازی و فیلتر.

مراحل

  1. داده‌ها را در سلول‌های A1 تا E11 وارد کنید.
  2. به جدول یک استایل زیبا بدهید: Home > Format as Table
  3. سرستون‌ها را پررنگ و وسط‌چین کنید.
  4. جدول را بر اساس ستون «نام شخصیت» به ترتیب الفبا مرتب کنید: Data > Sort
  5. فیلتر را فعال کنید: Data > Filter و فقط شخصیت‌های «کشته شده» را نمایش دهید.
  6. یک ستون جدید به نام «سن تقریبی» اضافه کنید و برای هر شخصیت یک عدد حدسی وارد کنید.

هدف: تمرین مرتب‌سازی، نمودار خطی و درج تاریخ.

  1. داده‌ها را وارد کنید.
  2. جدول را بر اساس ستون «فصل» مرتب کنید: Data > Sort
  3. یک ستون «تعداد کلمات کلیدی» اضافه کنید و برای هر رویداد یک عدد حدسی وارد کنید.
  4. نمودار خطی از «فصل» و «تعداد کلمات کلیدی» بسازید: Insert > Line Chart
  5. عنوان نمودار را «روند رویدادهای رمان» بگذارید.
  6. رنگ خط را قرمز کنید.

نمادهای کلیدی رمان

  1. در ستون C، درصد هر نماد را محاسبه کنید: =B2/SUM($B$2:$B$9)*100
  2. نمودار دایره‌ای بسازید: Insert > Pie Chart
  3. برچسب درصدها را روی نمودار نمایش دهید.
  4. عنوان: «نمادهای کلیدی رمان»
  5. رنگ هر بخش را متناسب با نماد تغییر دهید (مثلاً آب = آبی، خشت = قهوه‌ای).

🎨 تمرین ۵: قالب‌بندی شرطی و فیلتر پیشرفته Conditional Formatting و Filter

هدف: تمرین Conditional Formatting و Filter.
📋 داده‌ها: همان جدول شخصیت‌های تمرین ۱ را کپی کنید.
  1. ستون «وضعیت» را انتخاب کنید.
  2. از Home > Conditional Formatting > Highlight Cells Rules > Text that Contains استفاده کنید.
  3. برای «کشته شده» رنگ قرمز و برای «زنده» رنگ سبز انتخاب کنید.
  4. فیلتر را روی ستون «نقش» اعمال کنید و فقط «نوازنده چنگ» و «فرمانروا» را نمایش دهید.
  5. یک ستون «امتیاز محبوبیت» اضافه کنید و اعداد ۱ تا ۱۰ وارد کنید.
  6. با استفاده از Data Bars در Conditional Formatting، امتیازها را به صورت نوار رنگی نمایش دهید.

📊 تمرین ۶: جدول محوری (Pivot Table) ساخت Pivot Table و خلاصه‌سازی داده‌ها

هدف: تمرین ساخت Pivot Table و خلاصه‌سازی داده‌ها.

جدول شخصیت‌های تمرین ۱ را با یک ستون «جنسیت» گسترش دهید:

نام نقش جنسیت وضعیت

مامورونان‌پززنزنده
  1. داده‌ها را وارد کنید.
  2. از Insert > PivotTable یک جدول محوری بسازید.
  3. «جنسیت» را به Rows و «وضعیت» را به Columns بکشید.
  4. «نام» را به Values بکشید (Count).
  5. نتیجه: چند زن و چند مرد زنده یا کشته شده‌اند.
  6. یک نمودار محوری از این جدول بسازید.

✅ تمرین ۷: تمرین ترکیبی — گزارش نهایی ترکیب همه مهارت‌ها در یک کاربرگ

هدف: ترکیب همه مهارت‌ها در یک کاربرگ.
  1. یک کاربرگ جدید باز کنید.
  2. عنوان «گزارش رمان زمین خواهد شنید» را در سلول A1 بنویسید و آن را بزرگ و پررنگ کنید.
  3. جدول شخصیت‌ها، مکان‌ها و نمادها را در سه شیت جداگانه وارد کنید.
  4. در شیت چهارم، یک خلاصه بسازید:
    • تعداد کل شخصیت‌ها
    • تعداد کشته‌شدگان
    • تعداد مکان‌ها
    • پرتکرارترین نماد
  5. یک نمودار دایره‌ای از وضعیت شخصیت‌ها (زنده / کشته) بسازید.
  6. فایل را با نام پروژه_اکسل_رمان.xlsx ذخیره کنید.
