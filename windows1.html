آشنایی با دسکتاپ

روی فضای خالی دسکتاپ راست‌کلیک کنید و گزینه‌ی Personalize را ببینید. اینجا می‌توانید تصویر پس‌زمینه را به تصویر سنگ‌نگاره‌های رمان تغییر دهید.

نوار وظیفه (Taskbar)

پایین صفحه، نوار وظیفه قرار دارد. شامل: منوی Start، جستجو، برنامه‌های پین‌شده، آیکون‌های سیستم و ساعت.

پین کردن برنامه‌ها

روی Word راست‌کلیک و Pin to taskbar را بزنید تا همیشه در دسترس باشد.

منوی Start

روی آیکون ویندوز یا Win کلیک کنید. جستجو برای: Word، Notepad، Cmd.

تنظیمات سریع

با Win+I پنجره‌ی Settings باز می‌شود. در بخش System > Display می‌توانید رزولوشن را تنظیم کنید.

System Tray

گوشه‌ی راست-پایین ساعت و آیکون‌های شبکه، صدا، باتری قرار دارند. روی ساعت کلیک کنید تا تاریخ و تقویم را ببینید.

چند پنجره‌ای کار کردن

با Win+← یا Win+→ پنجره‌ها را نصف صفحه کنید. با Alt+Tab بین آن‌ها جابه‌جا شوید.

✅
تمرین عملی: یک پوشه به نام «پروژه_رمان» روی دسکتاپ بسازید و آن را برای مراحل بعدی نگه دارید.

New FolderRenameNaming RulesExtensions
باز کردن File Explorer

با Win+E پنجره‌ی Explorer باز می‌شود. به مسیر This PC › Documents بروید.

ساخت پوشه‌ی اصلی

قواعد نام‌گذاری

در نام‌گذاری فایل‌ها از فاصله استفاده نکنید؛ به جای آن underline (_) یا dash (-) بگذارید. مثال: خلاصه_رمان.docx

تغییر نام (Rename)

روی فایل کلیک کنید و F2 را بزنید، یا راست‌کلیک → Rename.

نمایش پسوند فایل‌ها

⚠️
مهم: در نام فایل‌ها از این کاراکترها استفاده نکنید: \ / : * ? " < > | — ویندوز آن‌ها را نمی‌پذیرد.

کپی، انتقال و حذف فایل‌ها

⏱ ۳۵ دقیقه 📊 سطح: مبتدی 🎯 هدف: Copy, Move, Delete
CopyCutPasteDeleteRecycle Bin
کپی کردن (Copy)

فایل را انتخاب و Ctrl+C بزنید. یا راست‌کلیک → Copy.

چسباندن (Paste)

به پوشه‌ی مقصد بروید و Ctrl+V بزنید.

برش (Cut) برای انتقال

فایل را انتخاب و Ctrl+X بزنید، سپس در مقصد Ctrl+V. این کار فایل را منتقل می‌کند.

حذف به سبد بازیافت

فایل را انتخاب و Delete بزنید. فایل به Recycle Bin می‌رود و قابل بازیابی است.

حذف دائمی

Shift+Delete فایل را برای همیشه حذف می‌کند (بدون Recycle Bin).

انتخاب چندتایی

با Ctrl+کلیک، فایل‌های پراکنده را انتخاب کنید. با Shift+کلیک، یک محدوده‌ی پیوسته را انتخاب کنید.

بازیابی از Recycle Bin

روی آیکون سبد بازیافت دسکتاپ دوبار کلیک کنید. فایل را انتخاب و Restore را بزنید.

💡
تفاوت Copy و Cut: Copy فایل را تکثیر می‌کند (اصل فایل می‌ماند)، اما Cut فایل را جابه‌جا می‌کند (اصل حذف می‌شود).

جستجو، مرتب‌سازی و فشرده‌سازی

⏱ ۴۰ دقیقه 📊 سطح: متوسط 🎯 هدف: Search, Sort, Compress
SearchSortFilterCompress (ZIP)Extract
جستجوی فایل

در نوار جستجوی Explorer بنویسید: *.docx تا همه‌ی فایل‌های Word را پیدا کنید. یا خلاصه* تا فایل‌هایی که با «خلاصه» شروع می‌شوند.

مرتب‌سازی (Sort)

در پوشه، راست‌کلیک → Sort by → Name / Date / Type / Size. مثلاً فایل‌ها را بر اساس تاریخ مرتب کنید.

فیلتر کردن

از تب View › Sort › Filter می‌توانید فقط فایل‌های Word یا تصویر را نمایش دهید.

فشرده‌سازی (ZIP)

پوشه‌ی Zamin_Khahad_Shenid را انتخاب و راست‌کلیک → Send to → Compressed (zipped) folder. یک فایل ZIP ساخته می‌شود.

استخراج (Extract)

روی فایل ZIP راست‌کلیک → Extract All تا محتوای آن باز شود. این برای بازیابی پشتیبان مفید است.

پشتیبان‌گیری

فایل ZIP را در پوشه‌ی 05_پشتیبان کپی کنید. هر هفته یک نسخه‌ی جدید با تاریخ (مثلاً backup_1405-07-15.zip) بسازید.

🏆
نکته‌ی حرفه‌ای: همیشه از پروژه‌های مهم پشتیبان تهیه کنید. ضرب‌المثل کامپیوتری: «پشتیبان نگیری، گریه‌ات را کسی نمی‌بیند.»

پروژه‌ی نهایی CMD — اتوماسیون با Batch

⏱ ۶۰ دقیقه 📊 سطح: پیشرفته 🎯 هدف: ساخت فایل .bat
Batch Fileecho@echo offpausestart
🤖
سناریو: می‌خواهیم یک فایل خودکار (Batch) بسازیم که با یک کلیک، تمام پوشه‌های آبادی‌های رمان را ایجاد کند و فایل‌های متنی اولیه را در آن‌ها قرار دهد.
Notepad — setup_zamin.bat
@echo off
:: اسکریپت ساخت پروژه‌ی رمان زمین خواهد شنید
:: نویسنده: آموزشگاه تیروتیر
:: تاریخ: ۱۴۰۵
 
cls
echo ============================================
echo پروژه‌ی رمان «زمین خواهد شنید»
echo ساخته شده در آموزشگاه تیروتیر
echo ============================================
echo.
 
:: رفتن به درایو D
D:
cd \
 
:: ساخت پوشه‌ی اصلی
if not exist "Zamin_Project" mkdir "Zamin_Project"
cd Zamin_Project
 
:: ساخت پوشه‌های آبادی‌ها
for %%F in (کهباد گلِ_شور شیل‌هی‌تی اشکفت‌سلمان خونگ‌آژدر آیاپیر دزپارت) do (
mkdir "%%F"
echo نام آبادی: %%F > "%%F\README.txt"
echo این پوشه مربوط به آبادی %%F در رمان است. >> "%%F\README.txt"
)
 
:: ساخت فایل راهنما
echo پروژه‌ی رمان زمین خواهد شنید > "درباره.txt"
echo نوشته‌ی داریوش علیپور >> "درباره.txt"
echo ساخته شده در تیروتیر >> "درباره.txt"
 
echo.
echo ✓ پروژه با موفقیت ساخته شد!
echo ✓ ۷ پوشه‌ی آبادی ایجاد شد.
echo.
pause
ساخت فایل Batch

Notepad را باز کنید و کد بالا را در آن کپی کنید. سپس از File › Save As با نام setup_zamin.bat و نوع فایل All Files ذخیره کنید.

اجرای فایل Batch

روی فایل setup_zamin.bat دوبار کلیک کنید. یک پنجره‌ی CMD باز می‌شود و اسکریپت اجرا می‌شود.

بررسی نتیجه

به درایو D بروید و پوشه‌ی Zamin_Project را ببینید. داخل آن ۷ پوشه‌ی آبادی و فایل README در هر کدام وجود دارد.

توضیح دستورات

@echo off: نمایش دستورات را خاموش می‌کند. echo: متن نمایش می‌دهد یا در فایل می‌نویسد. >: نوشتن در فایل (جایگزینی). >>: افزودن به فایل. pause: منتظر فشردن کلید می‌ماند.

حلقه‌ی for

دستور for %%F in (لیست) برای هر آیتم در لیست، دستورات داخل پرانتز را اجرا می‌کند. این کار ساخت ۷ پوشه را در یک خط ممکن می‌کند.

⚠️
هشدار امنیتی: هرگز فایل‌های .bat ناشناس را از اینترنت دانلود و اجرا نکنید. فایل‌های Batch می‌توانند دستورات خطرناکی مثل پاک کردن فایل‌ها را اجرا کنند.
🏆
تبریک! اگر این پروژه را کامل کردید، به سطح پیشرفته‌ی CMD رسیده‌اید و می‌توانید کارهای تکراری را با Batch File خودکار کنید.
