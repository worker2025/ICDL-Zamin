🗄️ تمرین اکسس بر اساس رمان «زمین خواهد شنید»

ساخت پایگاه داده‌ی رمان

از جدول شخصیت‌ها تا گزارش خراج — آموزش گام‌به‌گام Microsoft Access با محتوای رمان

🎯 معرفی پروژه

در این تمرین‌ها، یک پایگاه داده‌ی کوچک برای مدیریت اطلاعات رمان «زمین خواهد شنید» می‌سازیم. شامل جدول‌های شخصیت‌ها، مکان‌ها، کالاها (خراج) و رویدادها. سپس با کوئری، فرم و گزارش کار می‌کنیم.

💡 پیش‌نیاز: نصب Microsoft Access روی سیستم شما. اگر Access ندارید، می‌توانید از LibreOffice Base به عنوان جایگزین رایگان استفاده کنید.

🧱 تمرین ۱: ساخت پایگاه داده و جدول‌ها

هدف: آشنایی با ایجاد جدول، تعیین کلید اصلی و ورود داده.

۱-۱. ایجاد پایگاه داده

  1. Access را باز کنید.
  2. گزینه‌ی Blank Database را انتخاب کنید.
  3. نام فایل را Zamin_Database.accdb بگذارید و ذخیره کنید.

🔗 تمرین ۲: ایجاد رابطه بین جدول‌ها

هدف: آشنایی با Relationships و یکپارچگی داده‌ها.

  1. از تب Database Tools گزینه‌ی Relationships را انتخاب کنید.
  2. جدول‌ها را اضافه کنید: tblCharacters، tblLocations، tblGoods، tblTribute، tblEvents.
  3. رابطه‌های زیر را ایجاد کنید (فیلدها را بکشید و رها کنید):
  4. گزینه‌ی Enforce Referential Integrity را فعال کنید.
  5. ذخیره کنید.
tblLocations.LocationID → tblCharacters.LocationID
tblLocations.LocationID → tblEvents.LocationID
tblGoods.GoodID → tblTribute.GoodID
✅ نکته: با فعال‌سازی Referential Integrity، نمی‌توانید رکوردی را حذف کنید که در جدول دیگر به آن ارجاع شده است. این کار یکپارچگی داده‌ها را تضمین می‌کند.

🔍 تمرین ۳: کوئری‌ها (Query)

هدف: آشنایی با Select Query، Calculated Field و Totals.

کوئری ۱

نمایش شخصیت‌ها با مکانشان

  1. Create > Query Design
  2. جدول‌های tblCharacters و tblLocations را اضافه کنید.
  3. فیلدهای Name، Role، Status و LocationName را انتخاب کنید.
  4. اجرا کنید: Run.
کوئری ۲

شخصیت‌های کشته شده

  1. کوئری جدید بسازید.
  2. جدول tblCharacters را اضافه کنید.
  3. فیلد Name و Status را انتخاب کنید.
  4. در Criteria زیر Status بنویسید: "کشته شده"
  5. اجرا کنید.
کوئری ۳

مجموع خراج هر کالا

  1. Create > Query Design
  2. جدول‌های tblTribute و tblGoods را اضافه کنید.
  3. فیلدهای GoodName و Quantity را انتخاب کنید.
  4. از تب Design گزینه‌ی Totals را فعال کنید.
  5. در ردیف Total زیر Quantity، Sum را انتخاب کنید.
  6. اجرا کنید: مجموع خراج هر کالا نمایش داده می‌شود.
کوئری ۴

فیلد محاسباتی (دو برابر خراج)

  1. کوئری جدید با جدول tblTribute.
  2. فیلد GoodID و Quantity را اضافه کنید.
  3. در یک ستون خالی بنویسید: DoubleQty: [Quantity]*2
  4. اجرا کنید.

📝 تمرین ۴ و ۵: فرم و گزارش

📋

تمرین ۴: فرم شخصیت‌ها

هدف: آشنایی با Form Wizard.

  1. تب Create > Form Wizard
  2. جدول tblCharacters را انتخاب کنید.
  3. همه فیلدها را اضافه کنید.
  4. چیدمان Columnar را انتخاب کنید.
  5. عنوان فرم را «فرم شخصیت‌ها» بگذارید.
  6. Finish — در فرم می‌توانید رکوردها را مرور، ویرایش یا اضافه کنید.
📄

تمرین ۵: گزارش خراج کالاها

هدف: آشنایی با Report Wizard.

  1. تب Create > Report Wizard
  2. از کوئری ۳ (مجموع خراج هر کالا) استفاده کنید.
  3. فیلدهای GoodName و SumOfQuantity را انتخاب کنید.
  4. گروه‌بندی بر اساس GoodName.
  5. مرتب‌سازی بر اساس SumOfQuantity نزولی.
  6. چیدمان Stepped و جهت Portrait.
  7. عنوان گزارش: «گزارش خراج کالاها».
  8. Finish.
